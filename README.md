## 📖 Sobre el proyecto

Herramienta mínima para lanzar tokens de pump.fun en masa usando RPC normal: sin Jito y sin dev buy. Un solo servidor, dependencias mínimas.

## ✨ Qué hace

- Lanzamiento en masa vía `@pump-fun/pump-sdk`
- RPC plano: sin bundles de Jito ni compra del dev
- Un solo archivo de servidor
